# OSA & Field Execution Analytics

Портфолио-разбор Power BI отчёта по OSA, покрытию, визитам, доле полки и показателям полевого исполнения.

> Данные внутри исходного отчёта намеренно устаревшие. Это демонстрационный снимок; обновление не требуется.

## Что показывает отчёт

Отчёт объединяет сводные KPI и детализацию по ассортименту, торговым точкам, регионам и торговым сетям. В нём 22 страницы по темам покрытия, визитов, OSA, доли полки, ДМП, план/факта, фейзинга и отсутствующих SKU.

В сохранённом состоянии за август 2026 года на сводной странице были видны: выполнение визитов — 99%, покрытие — 89%, OSA — 63%, доля полки — 102%, ДМП — 13%. Это исторические значения, приведённые только для демонстрации сохранённого отчёта.

## Файлы проекта

- analysis.md — обзор показателей, страниц, источников и модели.
- model/relationships.mmd — схема выбранных связей.
- model/calculated-tables.dax — вычисляемые таблицы DAX, прочитанные в Power BI.

## Источники и безопасность

Исходная модель использует MySQL и Excel-файлы на внутренней сетевой папке. Адреса серверов и пути к источникам не публикуются. Рабочий PBIX, корпоративные выгрузки, учётные данные и внутренние идентификаторы в репозиторий не добавлены.

Полный SQL/M-код и меры DAX требуют отдельного экспорта и проверки. Логика формул не восстанавливается по одним значениям визуалов.
