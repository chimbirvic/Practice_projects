# OSA & Field Execution Analytics

Портфолио-разбор Power BI отчёта по OSA, покрытию, визитам, доле полки и дополнительным показателям полевого исполнения.

> Данные внутри исходного отчёта намеренно устаревшие. Это безопасный демонстрационный снимок: актуализация и подключение к рабочим источникам для портфолио не требуются.

## Что показывает отчёт

Отчёт объединяет KPI и детализацию по товарному ассортименту, торговым точкам, регионам и торговым сетям. На сводной странице отображаются покрытие, выполнение визитов, OSA, доля полки и ДМП. Дополнительные страницы раскрывают динамику по месяцам, разрезы по SKU и точкам продаж, федеральным и локальным сетям, отсутствующие позиции, план/факт и фейзинг.

В просмотренном снимке был выбран август 2026 года. На странице main отображались: выполнение визитов — 99%, покрытие — 89%, OSA — 63%, доля полки — 102%, ДМП — 13%. Эти значения приведены только как пример сохранённого состояния отчёта, не как текущие бизнес-показатели.

## Защита данных перед публикацией

Исходные подключения ведут к внутренним ресурсам. Не добавляйте в публичный репозиторий адреса серверов и сетевых папок, логины, пароли, токены, имена клиентов и торговых точек, выгрузки из рабочей базы или исходный PBIX без проверки его содержимого. Для демонстрации используйте обезличенные скриншоты и синтетические данные.

## Статус анализа

Структура отчёта, названия страниц, типы источников, часть связей и две вычисляемые таблицы проверены по открытому Power BI Desktop. Полный текст SQL, все M-шаги и все меры DAX в этот черновик не включены: их нужно отдельно экспортировать из файла отчёта, не запуская обновление источников.
