OSA & Field Execution Analytics
Портфолио-разбор Power BI отчёта по OSA, покрытию, визитам, доле полки и дополнительным показателям полевого исполнения.
Данные внутри исходного отчёта намеренно устаревшие. Это демонстрационный снимок; обновление данных не требуется.
Что показывает проект
Отчёт объединяет сводные KPI и детализацию по товарному ассортименту, торговым точкам, регионам и торговым сетям. В нём 22 страницы по темам покрытия, визитов, OSA, доли полки, ДМП, план/факта, фейзинга и отсутствующих SKU.
В сохранённом состоянии (август 2026 года) на сводной странице были видны: выполнение визитов — 99%, покрытие — 89%, OSA — 63%, доля полки — 102%, ДМП — 13%. Эти значения исторические и приведены только как демонстрация состояния отчёта.
Структура
	•	analysis.md — обзор метрик, страниц, источников и модели данных. 
	•	model/relationships.mmd — схема выбранных связей модели. 
	•	model/calculated-tables.dax — две вычисляемые таблицы DAX, прочитанные в Power BI. 
Данные и безопасность
Источники исходного отчёта включают MySQL и Excel-файлы на внутренней сетевой папке. Адреса и пути источников не публикуются. Рабочий PBIX, выгрузки из корпоративной базы, учётные данные и внутренние идентификаторы в этот репозиторий не добавляются.
Некоторые меры DAX и полный код SQL/M требуют отдельного экспорта и проверки. Их логика здесь не выдумывается по одним значениям визуалов.
