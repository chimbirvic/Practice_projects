# Источники данных

## Подтверждённые типы источников

1. **MySQL** — запрос fact использует MySQL.Database и выполняет собственный SQL-запрос к базе analytics. В интерфейсе Power BI видны поля, связанные с проектом, маршрутом и торговой точкой.
2. **Excel-файлы** — для запроса OSA_08_2025 шаг Source использует Excel.Workbook(File.Contents(...)) с файлом на внутренней сетевой папке. Точный UNC-путь и адрес сервера намеренно опущены.
3. **Периодические запросы** — в Power Query видны серии имён OSA_… и DP_…, а также таблицы-справочники и запросы планов/фактов.

## Запросы, видимые в редакторе

Power Query показывал 36 запросов. Среди прочитанных имён: OSA_09_2025, OSA_08_2025, analytics_all_ap, DMP, response, reports_old, sku, category, matrix, plan_new_visits, plan, fact, Доля план, cancel, actual_matrix, reports, а также месячные запросы OSA_… и DP_…. Название одного справочника торговых точек в интерфейсе обрезано.

Для OSA_08_2025 видны шаги Source, Navigation, Promoted Headers, Filtered Rows. Последний шаг фильтрует строки, где Month не пустой и не null.

## Публикация подключений

В репозитории описывайте только тип источника и его роль. Не публикуйте сервер, сетевой путь, внутренние имена БД, учётные данные и идентификаторы из SQL. Для повторного запуска укажите, что нужны корпоративные подключения и разрешённый доступ к источникам; демонстрационный репозиторий не должен выполнять обновление.
