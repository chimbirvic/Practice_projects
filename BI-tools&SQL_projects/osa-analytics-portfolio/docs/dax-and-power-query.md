# DAX и Power Query

## Подтверждённые вычисляемые таблицы DAX

В Power BI были прочитаны выражения таблиц matrices и calend. Код записан в ../model/calculated-tables.dax.

- matrices — выделяет уникальные ID из таблицы matrix через SUMMARIZE.
- calend — объединяет наборы месяц/год из plan_new_visits и OSA_all, затем формирует таблицу по месяцу и году. Это помогает согласовать временную ось разных фактовых источников.

Эти выражения — **вычисляемые таблицы**, а не меры. Полные формулы мер KPI ещё не извлечены; названия и значения карточек не позволяют достоверно восстановить их логику.

## Power Query и SQL

- fact — единственный видимый шаг Source, использующий MySQL.Database с нативным SQL SELECT.
- OSA_08_2025 — Excel.Workbook(File.Contents(...)), затем навигация, повышение заголовков и фильтрация пустого месяца.
- В редакторе было 36 запросов, в том числе месячные OSA_… и DP_…, справочники, планы и факты.
- В списке запросов предупреждения были видны у reports_old, sku, actual_matrix и reports. Причины и влияние нужно проверить в диагностике PBIX.

## Что стоит включить в окончательную версию анализа

1. Полный SQL для fact, с заменой адресов и имён приватных сущностей.
2. M-код наиболее важных запросов, шаги преобразований, фильтры, типы данных и места, где загрузка отключена.
3. DAX для KPI покрытия, визитов, OSA, доли полки и ДМП.
4. Контекст вычисления: знаменатель процентов, обработка пустых значений, период сравнения, влияние фильтров.
5. Отдельное описание того, какие таблицы являются фактами, измерениями, мостами и вычисляемыми таблицами.

Пока не публикуйте формулы, восстановленные по цифрам на визуалах: это может неверно описать бизнес-правила.
