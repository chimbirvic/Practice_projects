# Состояние данных и обновление

Данные в проекте намеренно устаревшие — это решение владельца для защиты актуальной бизнес-информации. Их не нужно обновлять.

Для публичной версии:

- сохраняйте демонстрационный снимок как статичный;
- не запускайте Refresh и не добавляйте автоматизацию обновления;
- явно сообщайте в README, что значения исторические и предназначены для демонстрации структуры/аналитики;
- не публикуйте рабочее подключение или исходный набор данных;
- перед публикацией удалите или замените внутренние адреса, пути, логины и прочие параметры подключения.

В ходе первичной проверки Power BI показывал недоступность сетевых путей и требование разрешения на выполнение нативного запроса. Обновление не является частью этой демонстрации и не требуется для анализа сохранённой модели.
