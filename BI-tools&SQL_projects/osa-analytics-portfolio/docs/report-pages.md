# Страницы отчёта

В Power BI Desktop отображалось 22 страницы. Названия ниже переписаны из вкладок страниц; краткое назначение сформулировано по названию и видимому содержимому.

| № | Страница | Назначение |
|---:|---|---|
| 1 | Сводный Отчет | Сводная точка входа; содержит общий обзор показателей. |
| 2 | OSA свод 1 | Сводный анализ OSA. |
| 3 | main | Компоновка KPI: покрытие, визиты, OSA, доля полки и ДМП. |
| 4 | Покрытие | KPI и динамика покрытия. |
| 5 | Визитность | KPI выполнения визитов и динамика. |
| 6 | Визиты детально | Детализация визитов. |
| 7 | Детально: OSA по СКЮ | Детализация OSA по SKU. |
| 8 | Детально: OSA по ТТ | Детализация OSA по торговым точкам. |
| 9 | OSA динамика по регионам | Динамика OSA в региональном разрезе. |
| 10 | Нет матрицы | Разрез/список по отсутствию матрицы. |
| 11 | BG | Страница с отдельным разрезом BG. |
| 12 | ДП: Сводный | Сводный отчёт по ДП. |
| 13 | ДП: План/Факт | Сопоставление плана и факта по ДП. |
| 14 | ДП: Детально | Детализация ДП. |
| 15 | ДП: BG | Разрез ДП по BG. |
| 16 | Федеральные сети | OSA по федеральным сетям; в снимке — столбчатая диаграмма по сетям. |
| 17 | Локальные сети | Сравнение OSA локальных сетей/точек; в снимке видны значения по нескольким десяткам категорий на оси. |
| 18 | ТОП отсутствующих | Рейтинг отсутствующих SKU и сетей по среднему OSA; есть фильтры периода и географии. |
| 19 | ДМП: Сводный | Сводный KPI ДМП и региональные/окружные разрезы выполнения. |
| 20 | Фейзинг | Отдельная страница фейзинга. |
| 21 | Фейзинг: BG | Разрез фейзинга по BG. |
| 22 | Out SM | Дополнительная страница/разрез Out SM. |

## Переходы и фильтры

На ряде страниц видны кнопки навигации и фильтры региона/периода. Для полного описания навигации между страницами и взаимодействия визуалов понадобится отдельная проверка каждой страницы в PBIX.
