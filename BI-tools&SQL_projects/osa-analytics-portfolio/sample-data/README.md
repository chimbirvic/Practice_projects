# Демонстрационные данные

В этой папке допустимы только синтетические данные, созданные специально для публичной демонстрации. Не копируйте сюда выгрузки из корпоративных источников. По возможности сохраняйте схему и типы полей, заменяя идентификаторы и показатели случайными, но реалистичными значениями.
