# Скриншоты

Добавьте скриншоты после проверки на конфиденциальность:

- сводная страница с KPI;
- пример детализации OSA по SKU/торговой точке;
- региональный или сетевой разрез;
- снимок схемы модели.

Перед публикацией скройте торговые точки, клиентские названия, внутренние поля и другие идентификаторы. Сохраняйте выбранный намеренно устаревший период и подпишите его как демонстрационный.
