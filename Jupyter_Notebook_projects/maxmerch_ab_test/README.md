# MAXMERCH: A/B-тест экрана приоритизации задач

**Портфолио-кейс: MAXMERCH — вымышленный продукт; данные синтетические.** Далее проект описан внутри сценария кейса.

## Краткий вывод

Новый экран дал +0,54 п.п. к доле успешных визитов (95% ДИ: +0,09…+0,98 п.п., p=0,019). Результат статистически значим, но ниже бизнес-MDE +1 п.п.; защитные метрики и порог внедрения пройдены. По заранее заданному правилу рекомендация — не масштабировать без обоснования экономики эффекта.

## Бизнес-задача

Оценить, повышает ли экран с группировкой и приоритетами задач долю запланированных визитов, где выполнены все обязательные действия, не ухудшая операционные метрики.

## Дизайн эксперимента

- 3 000 мерчендайзеров, рандомизация 1:1 на уровне пользователя, стратифицированная по городу, стажу и платформе.
- 2 недели pre-period и фиксированные 6 недель теста; основная оценка — intention-to-treat.
- H₀: разность средних пользовательских долей равна 0. H₁: разность отличается от 0; двусторонний тест, α=0,05.
- Плановая мощность 80%, бизнес-MDE +1 п.п.
- Основной тест — Welch t-test по агрегированной метрике каждого мерчендайзера; повторные визиты одного человека зависимы.

## Что внутри

- MAXMERCH_AB_test_analysis.ipynb — QA данных, формирование ITT-метрики, SRM и баланс, расчёт выборки, основной тест, защитные метрики, сегменты и рекомендация.
- experiment_protocol.md — метрики, гипотезы, правила остановки и пороги решения.
- generate_data.py — генератор всех таблиц с фиксированным seed.
- data_generation_metadata.json — состав и размеры наборов.
- requirements.txt — библиотеки для запуска.

## Запуск

CSV не включены в репозиторий, чтобы не хранить большие генерируемые файлы. Из папки проекта установите зависимости из requirements.txt, затем выполните python generate_data.py. Скрипт создаст таблицы в data/. После этого откройте MAXMERCH_AB_test_analysis.ipynb в Jupyter.
