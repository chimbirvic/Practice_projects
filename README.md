# Practice_projects

Портфолио с учебными и практическими проектами по аналитике данных: Python, SQL, EDA, A/B-тесты и BI.

## Избранный проект

### [MAXMERCH — A/B-тест экрана приоритизации задач](Jupyter_Notebook_projects/maxmerch_ab_test/)

Портфолио-кейс с синтетическими данными. Полный цикл эксперимента: проверка качества данных и рандомизации, расчёт выборки, ITT-анализ на уровне мерчендайзера, оценка защитных метрик и рекомендация по запуску. Оценка эффекта — +0,54 п.п. (p=0,019), ниже заранее заданного бизнес-порога +1 п.п.; поэтому результат не трактуется как основание для масштабирования.

## Структура репозитория

- [Jupyter_Notebook_projects](Jupyter_Notebook_projects/) — EDA, A/B-тесты и другие исследовательские проекты на Python.
- [BI-tools&SQL_projects](BI-tools%26SQL_projects/) — проекты с PostgreSQL, SQL и визуализацией в Yandex DataLens.

## Инструменты

Python, SQL, pandas, NumPy, Matplotlib, Seaborn, SciPy, statsmodels, PostgreSQL, Yandex DataLens, Jupyter Notebook и DBeaver.

Проекты в репозитории могут быть учебными, практическими или портфолио-кейсами; формат и особенности данных указаны в README соответствующего проекта.
